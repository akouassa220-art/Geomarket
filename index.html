Une API REST simple, des tuiles prêtes pour Leaflet et MapLibre, et des téléchargements par lien sécurisé.

Requêtes spatialesFiltrez par emprise, par commune ou par attribut.

Clés API révocablesGérez vos clés et suivez votre usage depuis votre espace.

# Routes bitumées dans la commune de Cocody
curl https://api.geomarket.ci/v1/datasets/routes-civ/features \
  -H "X-API-Key: gm_live_xxxxxxxx" \
  -G -d "commune=cocody" -d "revetement=bitume"

Contribuer

Vous avez des données de terrain ? Partagez-les.

Les contributions sont contrôlées automatiquement, puis validées par un modérateur avant d'être publiées.

  1. Étape 1

    Soumission

    Envoyez un fichier GPKG, GeoJSON, SHP ou CSV.

  2. Étape 2

    Contrôle automatique

    Géométries, système de coordonnées, attributs, emprise.

  3. Étape 3

    Revue

    Un modérateur vérifie la carte et les doublons.

  4. Étape 4

    Approbation

    Vous recevez une notification et votre attribution.

  5. Étape 5

    Publication

    Vos données rejoignent le catalogue.
